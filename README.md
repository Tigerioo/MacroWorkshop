# 宏工坊 MacroWorkshop

《魔兽世界：无限》的技能宏助手。插件扩展游戏自带的宏窗口：从预设或技能生成宏，预览后创建新宏，或填入当前选中的已有宏。

## 安装

将仓库内的 `MacroWorkshop` 文件夹复制到无限服客户端的 `Interface/AddOns/` 目录，使 `MacroWorkshop.toc` 直接位于该文件夹内。重启游戏并启用插件。

## 使用

1. 输入 `/macro` 打开系统宏窗口，点击「宏工坊」展开助手；也可输入 `/mw` 打开。系统窗口继续负责浏览、编辑、删除和拾取账号通用宏及当前角色宏。
2. 在「预设模板」按通用、职业和用途查找示例，或在「按技能生成」拖入技能、输入技能名称或 ID，选择普通施法、自动攻击、焦点、鼠标指向或自身施法。示例技能可以修改，宏预览可复制。
3. 选择「新建宏」创建，或在系统窗口选择已有宏后点击「填入当前宏」。填入前会显示当前编辑内容和新内容，确认后替换系统编辑框；系统可能在切换宏或关闭窗口时自动保存。
4. 「宏标签」可给当前宏手动分类并筛选。标签仅在本次登录期间有效，宏列表变化或重新载入后需要重新标记；标签不改变系统宏的保存范围或正文。

战斗中不可修改宏；游戏的图标选择器打开时助手会暂时隐藏。宏栏已满、重名、客户端接口不可用或目标变化时，插件会提示并保留生成预览。创建后仍需玩家从系统窗口手动拾取并放到动作条；插件不会自动施法。

焦点和鼠标指向的回退选项不判断距离或视线。自动攻击只适合需要近战普攻的技能；职业模板是可编辑示例，技能名和实际效果须在客户端核对。

## 验证状态

目标接口版本为 `16001`。当前改版已在本机 Lua 5.1 模拟宏接口与系统窗口路径；尚未在《魔兽世界：无限》客户端验收。系统窗口接入、技能拖入、宏保存和战斗限制、不同窗口位置以及其他插件兼容性均需实机检查。可在游戏内运行 `/dump select(4, GetBuildInfo())` 查看接口版本。
