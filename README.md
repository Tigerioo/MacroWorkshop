# 宏工坊 MacroWorkshop

《魔兽世界：无限》的技能宏创建助手。输入 `/mw` 打开窗口，将技能从技能书拖入，或填写客户端语言的技能名，选择模板后预览并创建游戏原生宏。

支持普通施法、自动攻击加技能、焦点、鼠标指向和对自己施法。焦点和鼠标指向可选在目标无效时按游戏默认方式施法；该选项不判断距离或视线。自动攻击模板只适合需要近战普攻的技能，请按职业和场景选择。

## 安装

将仓库内的 `MacroWorkshop` 文件夹复制到无限服客户端的 `Interface/AddOns/` 目录，使 `MacroWorkshop.toc` 直接位于该文件夹内。重启游戏并启用插件。具体客户端目录以实际安装位置为准。

## 使用与限制

1. 脱战后输入 `/mw`，从技能书拖入技能，或输入技能名称或法术 ID 并按回车。
2. 选择模板，检查宏预览、名称和角色专用选项，然后点击「创建宏」。已有同名宏不会被覆盖。
3. 创建成功后点击「拾取宏」，再放到动作条。也可以选中预览文字复制到游戏的 `/macro` 窗口。

宏由游戏保存，使用仍需玩家按键；本插件不会自动施法。战斗中不能创建宏。宏数量、长度和客户端权限受游戏限制；创建失败时会显示提示，并保留预览以便手工创建。技能来源、宏条件及目标规则会因客户端版本和技能而异，请在游戏内检查。

## 验证状态

目标接口版本为 `16001`。当前尚未在《魔兽世界：无限》客户端验收；尤其需要检查技能书拖入、中文技能名、创建宏、拖到动作条、焦点与鼠标指向行为以及战斗限制。可在游戏内运行 `/dump select(4, GetBuildInfo())` 检查接口版本。
